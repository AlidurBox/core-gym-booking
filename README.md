# Core Gym Club Bokningssystem

Ett enkelt ASP.NET Core-projekt för ett bokningssystem till Core Gym Club.

Projektet är just nu bara teknisk grund. Funktioner som registrering, inloggning, bokningar och adminläge ska byggas stegvis senare.

## Starta lokalt

Krav:

- .NET SDK 9

Bygg projektet:

```bash
dotnet build
```

Starta applikationen:

```bash
dotnet run --project src/CoreGymBooking/CoreGymBooking.csproj
```

Öppna sedan webbadressen som visas i terminalen.
