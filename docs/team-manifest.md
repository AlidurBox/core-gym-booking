# Utvecklingsteamets manifest

## Projekt

Core Gym Club Bokningssystem

## Team

Alidur Hamid

## Ansvar

- Planering och user stories
- Implementation
- Git och pull requests
- Testning
- Dokumentation
- Presentation

## Arbetssätt

- Trello med listorna Backlog, To Do, In Progress, Testing och Done
- En feature-branch per funktion
- Pull requests mot `main`
- Stegvisa MVP-leveranser

## Gemensamma regler

- Ett Trello-kort flyttas till Done först när alla acceptanskriterier är
  testade.
- Varje funktion byggs i en egen branch och kommer in i `main` via en pull
  request.
- Projektet ska bygga utan fel innan en pull request skapas.
- Dagboken skrivs samma dag som arbetet görs.
- Dokumentationen beskriver bara arbete som faktiskt har gjorts.
